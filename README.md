# Powder Peak

A chill snowboard tricklining game: carve, ollie, flip and grind down big mountains, build your own stages, and unlock pro parks.

**Play / install:** https://murfeds.github.io/powder-peak/

On Android (Chrome): open the link, tap the menu, then **Install app** (or **Add to Home screen**). It works offline and shows "New version ready" when there's an update.
